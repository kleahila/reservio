## 🎯 What Each Screen Does

### 1. Registration
```
Input: Name, Email, Password
Validation: Required, Email format, Password length, Duplicate email
Output: Success → Redirect to Login
```

### 2. Login
```
Input: Email, Password (pre-filled: anna@example.com / demo123)
Validation: Credentials against mock users
Output: Success → Redirect to Dashboard
```

### 3. Dashboard
```
Display: Welcome message + Upcoming reservations + Quick links
Links: Rooms, Parking, Sunbeds, Marketplace
```

### 4. Room Browsing
```
Display: Card grid of all rooms
Features: Filter by status, responsive grid
Action: Click room → Room detail page
```

### 5. Room Detail
```
Display: Room details + Amenities
Input: Check-in date, Check-out date
Action: Book Now → Confirmation modal → Reference #
```

### 6. Parking Map
```
Display: Spot grid organized by zone
Status: Green (available), Red (occupied), Yellow (reserved)
Action: Click spot → Modal → Lock 5 min → Confirm/Cancel
```

### 7. Sunbed Map
```
Display: Sunbeds by zone with time slot selection
Tabs: 4 time slots (09:00-12:00, 12:00-15:00, etc.)
Action: Select sunbed → Modal → Lock 5 min → Confirm/Cancel
```

### 8. Marketplace
```
Display: Service cards by category
Features: Add to cart, quantity controls, checkout
Payment: Bill to room or pay now
```

### 9. Notifications
```
Display: Full notification list with filters
Features: Mark as read, delete, bulk actions
Filters: All, Unread, Offers
```
